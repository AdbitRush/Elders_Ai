# BrainPlay pre-launch audit - 2026-10-10

**What was tested:** the preview, https://games-preview.178-105-148-72.sslip.io (branch `preview/warm-redesign` @ d6e8cbc,
ASSET_V 65). The live site (`main`) has the same game code for everything in Part 2 unless noted.
**How:** Playwright on Or's PC (Chromium) with real clicks. Every game was played start -> wrong move -> right moves ->
end screen -> "Level 2" -> back to hub -> reopen, at 1280 px desktop/light **and** 390 px phone. Screenshots at
1440 and 390, light and dark, en/he/el. I read every game's source to know the right answers and to find root causes.
Design bar: seniors first - big, high-contrast, warm, satisfying feedback; ads between games only.

---

## Bottom line

**Broken games (1):** Falling Blocks. Game over never ends the session (no end screen, no restart, player is stuck on
"GAME OVER"), and the arrow keys / Space do nothing on a computer. Root cause: `js/games/blocks.js` reads
`window.gameState`, but `gameState` is declared with `let` in index.html, so it is never on `window`. Live site too.

**Broken in one language (1):** Hangman in Greek is unwinnable - all 10 Greek words, Latin A-Z keyboard.

**Defect in 14 games:** a double-tap (very common with seniors and tremors) is counted as two answers: it scores the
same answer twice and silently skips the next question. Math, Number Sequence, Odd One Out, Trivia, True/False,
Flags, Proverbs, Color Match, Clock, Quick Count, Categories, Missing Letter, Number Memory (OK button), Time Journey.

**Other real game bugs:** Picture Recall on Hard wipes your picks after 4 s; Number Sequence's "Fibonacci-looking"
puzzles have answers that follow no rule; every quiz says "Well Done!" with confetti and moves you up a level even at 0/10.

**Worst-looking problems:** no real logo (a letter "B" in a circle); the site doesn't feel nostalgic at all (stock
object photos, school-quiz questions like "How many days are in a week?"); on a phone the first game appears only
after about 3 screens of stats and text, and the hub is 19,000 px long; two game cards show Hebrew titles on the
English (and es/fr/de/el) site; lots of small grey text (98 text elements under 16 px on the hub).

**What I need from you:** see "Inputs I need from Or" below - logo/brand name, domain, nostalgic photo direction (or
real photos), the content era/country, AdSense ID + consent decision, legal pages, contact email.

**Summary:** 27 of 28 can be played to the end; 1 is broken everywhere (Falling Blocks). Hangman is broken in Greek

### Fixes, in the order I'd do them (none applied in this audit)

1. Falling Blocks: use `gameState` / `currentLang` directly (4 lines) and pass `{correct:score,total:score}`.
2. One shared "answer lock" for all quiz games: ignore taps until the next question renders (also fixes Time Journey
   and the digit-span OK button).
3. Hangman: a Greek keyboard (and accent folding for es/fr/de if accented words are ever added).
4. Recall Hard: clear the countdown when "Got them!" is pressed (or drop the countdown).
5. Number Sequence: make the 4th generator real Fibonacci (`a,b,a+b,a+2b -> 2a+3b`) or remove it.
6. Load `js/lang-content.js` before the first `changeLanguage()` (fixes the Hebrew cards).
7. End screen: score-based message + "Play again"; level up only above a threshold [Or #15].
